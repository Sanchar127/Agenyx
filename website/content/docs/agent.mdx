# Agent Service

The Agent service is the reasoning core of Agenyx. It accepts execution intents, plans and runs steps using LLMs, invokes tools (calculator, builtin, sandboxed), and persists execution state to PostgreSQL. It runs on port `8000`.

## Responsibilities

- **Reasoning** — plan and execute multi-step agent runs using an LLM.
- **Tool execution** — run builtin tools and calculator; route tool calls through the sandbox when isolation is needed.
- **MCP gateway routing** — connect to Model Context Protocol servers for external tools.
- **Persistence** — store executions, steps, and results in PostgreSQL (via SQLAlchemy/Alembic migrations).
- **Streaming** — stream runtime events to clients during execution.
- **Authorization & idempotency** — authorize actions and guarantee idempotent retries.
- **Crash recovery** — recover in-flight executions after worker or process failure.

## Key Capabilities

| Capability | Description |
|------------|-------------|
| LLM inference client | Calls the Inference service (`/v1/chat/completions`). |
| Tool registry | Registers and dispatches tools (e.g., calculator, builtin). |
| Tool executor | Runs tools with idempotency keys and result handling. |
| Planner | Decides the next step based on conversation state. |
| Decision engine | Chooses tools and arguments from LLM output. |
| Context manager | Manages conversation context and history. |
| Execution store | Persistent execution and step storage (PostgreSQL). |
| Event stream | Emits runtime events for streaming and observability. |
| Approval flow | Supports human-in-the-loop approval steps. |

## API Routes

The Agent service exposes authentication routes (`/auth/email/login`, `/auth/email/signup`) that are proxied through the Gateway, plus agent execution and tool routes handled directly by the Agent.

## Integration

- **Inference**: `AGENTYX_INFERENCE_BASE_URL` (default `http://inference:8004`)
- **Router**: `AGENTYX_ROUTER_BASE_URL` (default `http://router:8005`)
- **Sandbox**: `AGENTYX_SANDBOX_BASE_URL` (default `http://sandbox:9000`)
- **Database**: `AGENTYX_DATABASE_URL` (PostgreSQL)
- **MCP Gateway**: `AGENEYX_MCP_GATEWAY_TOKEN`

## Port

The Agent service runs on port `8000` and is reachable at `http://agent:8000` within Docker Compose.
