# Configuration

Agenyx subsystems are configured through environment variables and, for some services, YAML recipe/config files. Environment variables generally take precedence over file-based config.

## API Gateway

### Environment Variables

| Variable | Required | Default | Description |
|----------|----------|---------|-------------|
| `AGENEYX_API_KEY` | Yes | — | Bearer API key for `/v1/` routes |
| `AGENEYX_API_KEY_PERMISSIONS` | Yes | — | Comma-separated permissions (`agents:run`, `tasks:read`) |
| `AGENEYX_GATEWAY_RECIPE` | No | `recipes/gateway/default.yaml` | Path to gateway recipe YAML |
| `AGENEYX_AGENT_URL` | No | `http://agent:8000` | Agent upstream for `/auth/email/*` proxy |
| `AGENEYX_TRUSTED_PROXIES` | No | — | Trusted CIDRs for client IP resolution |
| `AGENEYX_CORS_ORIGIN` | No | — | Allowed CORS origin (`*` for any) |
| `AGENEYX_CORS_ALLOW_CREDENTIALS` | No | `false` | Enable credentials in CORS responses |

### Gateway Recipe (`recipes/gateway/default.yaml`)

```yaml
apiVersion: agenyx.ai/v1alpha1
kind: GatewayRecipe
metadata:
  name: default-gateway
  version: "1.0.0"
spec:
  rateLimit:
    requestsPerSecond: 10
    burst: 20
  request:
    maxBodyBytes: 1048576
```

| Field | Description | Default |
|-------|-------------|---------|
| `spec.rateLimit.requestsPerSecond` | Token refill rate | `10` |
| `spec.rateLimit.burst` | Bucket capacity | `20` |
| `spec.request.maxBodyBytes` | Max request body size | `1048576` (1 MiB) |

## Inference Service

Configuration is loaded from `config/inference.yaml`, with `INFERENCE_`-prefixed environment variables overriding YAML.

### Environment Variables (examples)

| Variable | Description |
|----------|-------------|
| `INFERENCE_SERVICE_API_KEY` | Required service-to-service API key |
| `INFERENCE_PROVIDER_NAMES` | Comma-separated provider names |
| `INFERENCE_PROVIDER_BACKENDS` | `name=url|type` provider mappings |
| `INFERENCE_MODEL_DEFINITIONS` | `model_id=provider_name` model mappings |
| `INFERENCE_OPENAI_API_KEY` | OpenAI-compatible provider API key |
| `INFERENCE_OTEL_EXPORTER_OTLP_ENDPOINT` | OTLP trace endpoint |

### Runtime Settings (`config/inference.yaml` → `runtime`)

| Setting | Default | Description |
|---------|---------|-------------|
| `max_retries` | `2` | Max retries per provider request |
| `request_timeout_seconds` | `120.0` | Upstream timeout |
| `max_connections` | `100` | HTTP max connections |
| `max_keepalive_connections` | `20` | HTTP max keepalive |
| `max_concurrency` | `10` | Concurrent admission limit |
| `max_failover_attempts` | `3` | Max failover attempts per model |

### Request Limits

| Setting | Default |
|---------|---------|
| `max_request_body_bytes` | `1048576` (1 MiB) |
| `max_messages` | `100` |
| `max_message_content_chars` | `100000` |
| `max_total_message_content_chars` | `500000` |
