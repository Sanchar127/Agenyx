# MCP Gateway

The MCP (Model Context Protocol) Gateway enables Agenyx agents to discover and invoke tools exposed by MCP-compliant servers. It acts as the bridge between the Agent service's tool ecosystem and external MCP servers.

## Responsibilities

- Discover tools and resources exposed by MCP servers.
- Route agent tool calls to the appropriate MCP server.
- Manage MCP client sessions and protocol framing.
- Authenticate MCP connections via `AGENEYX_MCP_GATEWAY_TOKEN`.

## Configuration

The MCP Gateway is configured through a gateway recipe (`recipes/mcp-gateway/default.yaml`):

```yaml
apiVersion: agenyx.ai/v1alpha1
kind: GatewayRecipe
metadata:
  name: mcp-gateway
spec:
  # MCP server endpoints and tool mappings
```

The token `AGENEYX_MCP_GATEWAY_TOKEN` must be set in the environment for the Agent service to authenticate with the MCP Gateway.

## Integration

The Agent service uses the MCP Gateway to extend its builtin tool set with capabilities exposed by external MCP servers (databases, file systems, APIs, etc.).
